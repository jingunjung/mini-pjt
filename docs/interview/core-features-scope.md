# 핵심 기능 · 범위

> Source: Deep Interview, 2026-09-02

## Key Points
- **여행 범위**: 국내 여행만 (MVP 범위를 좁혀 데이터/규칙을 단순화). 해외 여행(환율/비자/항공권
  등)은 이번 캡스톤 범위 밖.
- **예산 최적화 로직**: 사용자가 총 예산을 입력하면 항목별(숙박/식비/교통/관광)로 자동 배분.
- **최종 산출물 (3종 조합)**:
  1. 일자별 일정표 (Day1, Day2 ... 시간대별 활동)
  2. 예산 내역표 (항목별 지출 계획 vs 한도)
  3. 추천 근거/출처 표기 (왜 이곳을 추천했는지 — RAG 근거 문서 인용)

## Details
- 국내 한정이므로 환율 변환, 비자, 해외 안전 정보 같은 복잡한 변수는 배제하고, 국내 목적지/
  숙박/맛집/관광지 데이터에 집중할 수 있음.
- 예산 배분은 "총액 → 항목별 자동 배분"이 1차 로직. 항목 구성은 숙박/식비/교통/관광 4가지로
  확정. (세부 배분 비율이나 우선순위 조정 옵션은 이후 라운드에서 필요시 보강)
- 결과물 3종은 SERVICE.md "성공 기준"과 evaluation 설계에도 그대로 연결됨:
  - 일정표 → 구조화 출력(Day1 structured_output.py 패턴) 필요
  - 예산표 → 숫자 계산/검증 로직 필요 (LLM 산술 오류 가능성 → 툴/코드로 계산 위임 고려)
  - 추천 근거 → RAG 기반 출처 표기 (Day2 verify_sources.py, hallucination.py 패턴 재사용)

- 예산 계산을 LLM에 맡길지 별도 계산 도구(tool)로 분리할지 (환각 방지 관점에서 중요)
