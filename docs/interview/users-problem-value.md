# 사용자 · 문제 · 가치

> Source: Deep Interview, 2026-09-02
> SERVICE.md 1번 섹션 "사용자·문제·가치"에 대응

## Key Points
- **타겟 사용자**: 여행 계획 짜는 게 번거로운 직장인 — 짧은 휴가를 알차게 쓰고 싶지만 일정
  조사에 시간을 많이 쓰기 부담스러운 사람.
- **현재 대안 (에이전트가 없을 때)**:
  1. 블로그/유튜브 검색으로 여러 출처의 정보를 일일이 수집·정리
  2. 여행사/패키지 상품 이용 (비용 높고 개인화 안 됨)
  3. 지인에게 문의
- **핵심 가치(가장 우선)**: **예산 최적화** — 정해진 예산에 맞는 동선/일정을 자동으로 배분해줌.

## Details
- 문제의 본질은 "정보가 여기저기 흩어져 있어 예산에 맞는 일정을 짜는 데 시간이 오래 걸린다"는
  것. 여행사는 비싸고 개인화가 안 되며, 블로그/유튜브는 출처가 파편화되어 있고 예산 반영이 안 됨.
- 따라서 이 에이전트의 1순위 가치 제안은 "예산 최적화"이며, "시간 절약"과 "신뢰할 수 있는 출처
  기반 추천"은 2, 3순위 가치로 함께 제공되는 부가 가치로 볼 수 있음 (RAG로 뒷받침 가능).
- SERVICE.md 문구 초안:
  - 누구를 위한: "여행 일정을 짜는 데 시간과 에너지를 쓰기 부담스러운 직장인"
  - 어떤 문제: "예산에 맞는 여행 일정을 짜려면 여러 출처를 뒤져야 하고 시간이 오래 걸린다"
  - 대안 대비 개선: "여행사보다 저렴/개인화되고, 블로그 검색보다 빠르고 예산 반영이 정확함"
