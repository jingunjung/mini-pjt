# 예산 · 일정 규칙

> Source: Deep Interview, 2026-09-02

## Key Points
- **여행 기간/인원**: 1~7일, 인원수는 혼자~가족까지 가변 (사용자 입력에 따라 유동 처리).
- **예산 배분 방식**: 고정 비율이 아니라 **사용자 취향(맛집 중심/숨은여행지 중심 등)에 따라
  항목별 가중치를 조정**하는 개인화 로직.
- **계산 방식**: 예산 합계/배분 산술은 **LLM이 아닌 별도 계산 툴(코드)로 분리** — LLM 산술
  환각을 원천 차단.

## Details
- 인원수·기간이 가변이므로, 계산 툴의 입력 스키마는 최소한 다음을 포함해야 함:
  `총예산, 기간(일수), 인원수, 취향 태그(예: food/nature/hidden-gem/activity)`
- 가중치 조정 로직 예시안 (구현 시 확정):
  - 기본 배분: 숙박/식비/교통/관광에 대한 base weight
  - 취향 태그가 "맛집 중심"이면 식비 weight ↑, 관광 weight ↓ 등으로 조정
  - 최종적으로 항목별 배분액 = 총예산 × 조정된 weight 비율
- 계산 툴은 Day4(`tools_basic.py`, `tool_error.py`)의 `@tool` 데코레이터 패턴을 그대로 적용:
  파이썬 함수로 결정적 계산을 수행하고, Agent는 그 결과를 인용만 하도록 프롬프트로 강제.
- 이 결정은 SERVICE.md의 "가드레일" 섹션과도 연결됨 — "예산 숫자는 반드시 계산 툴 결과만 사용,
  LLM이 직접 산술한 숫자는 최종 답변에 포함하지 않는다"는 규칙으로 명문화 가능.

## Open Questions
- 취향 태그의 구체적 목록과 가중치 수치는 구현 단계에서 확정 필요 (예: food +10%p, 관광 -10%p 등)
- 인원수가 늘어날 때 숙박/식비가 어떻게 스케일링되는지 (1인 기준 단가 × 인원 방식 등) 확정 필요
